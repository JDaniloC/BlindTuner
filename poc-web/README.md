# BlindTuner — POC Web (Oficina de Luthier 2.5D)

Fatia vertical nivelada com a pesquisa avançada de geração procedural de [Desenvolvimento com IA]:

- **Sr. Arthur — Paradigma Paper-Cutout (Luthier Terracota):**
  - Sobretudo terracota em corte A-line com pesponto de alfaiataria pontilhado.
  - Colete azul marinho com botões de madrepérola e correntinha Albert dourada de relógio de bolso.
  - Cachecol de concerto aconchegante com franjas de lã.
  - Boina vintage com aba direcional 2.5D e óculos angulares com hastes anatômicas apoiadas nas orelhas (perfil sem deformação).
  - Violoncelo de Concerto artesanal com espigão de metal apoiado no chão e arco de pau-brasil com crina branca.
- **Cenário Isométrico Rigoroso:**
  - Janela vitoriana perfeitamente projetada na inclinação 2:1 da parede NW, com esquadria de madeira e feixe de luz volumétrica (God Ray) no piso.
  - Cama de carvalho com tapete ornamental bordô, edredom mostarda e travesseiros.
  - Abajur com iluminação quente difusa, rádio retrô com ondas analógicas, relógio de pêndulo oscilante e mesinha com chá fumegante.
- **Slider Fretboard de Luthier & UI:**
  - Braço de violoncelo em ébano lustrado, moldura de mogno, pestana de osso e inlays de madrepérola para cada nota natural.
  - Leitura em tempo real de nota e afinação precisa em centavos de Hz (ex.: `Lá (A4) • 430 Hz • -42¢`).
  - HUD em madeira e latão com trilha musical de contas esféricas cromáticas.
- **Áudio Acústico com ConvolverNode:**
  - Síntese modal livre de zumbidos acoplada a um `ConvolverNode` com Impulse Response da madeira real de violoncelo.

## Como rodar:
```bash
npm install
npm run dev
```
Abra `http://localhost:3000` no navegador.
